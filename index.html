Projects

Quora Question Research Automation

Turns a list of keywords into ready-to-use Quora content research, automatically.

An end-to-end Make workflow: feed it a list of keywords, and for each one it calls the serper.dev API (via HTTP) to fetch the top 10 related Quora questions — with link, date, and snippet — and logs them straight into Google Sheets. From there, selected questions get AI-generated answers, ready for content use.

N keywords → serper.dev API (HTTP) → Top 10 Quora questions per keyword (link, date, snippet) → Google Sheets → Selected questions answered via AI
Make serper.dev API Google Sheets AI-generated answers
